# Research systems contract
Use finite typed tasks and independent certificate checks. Record assumptions,
evidence, claim ceilings, falsifiers, budgets and stop rules. Never equate a finite
control or low residual with a universal proof. Keep local MCP default-off; close
only the exact temporary child. Public files must contain no private chats,
credentials, personal host paths, account identifiers or unrelated cloud metadata.
Catalog-only means no executable backend. No model-weight changes are implied.
